아이폰
- 단축어 설치 하시고 자신만 볼 수 있는 디스코드 채널 생성(봇은 볼 수 있어야함)
- 웹훅 만드시고 단축어 설정에 웹훅 링크 넣고
- 맨 밑에 자동화 클릭 -> + 버튼 클릭 -> 메시지 -> 보낸 사람은 입금 받았을때 문자 오는 전번
-> 메시지 포함 내용: 입금 -> 즉시 실행 -> 설정 한 단축어 선택
- 그 후 자충 설정에서 충전로그 채널 선택

단축어 링크: https://www.icloud.com/shortcuts/d50d44a3362945a291365ee6266d31b5

안드로이드
1. 플레이 스토어에서 PushBullet 설치
2. PushBullet 앱을 실행 후, 로그인 및 회원가입
3. 모든 권한을 허용한 뒤, 미러링을 접속
4. 알림 미러링만 나머지는 다 꺼주세요
5. 컴퓨터로 https://www.pushbullet.com/ 접속
6. 모바일에서 PushBullet으로 로그인했던 구글 계정으로 로그인
7. 컴퓨터로 https://www.pushbullet.com/#settings 를 접속
8. Account에 접속한 뒤, Create Access Token을 클릭하여, 토큰을 생성
9. 생성된 토큰을 복사한 뒤, 웹패널로 이동하여  붙여넣기
